# 我在 GitHub 随手一搜，发现了这个宝藏开源项目——免费替代 Tower 的团队任务管理神器

> 作者：某不知名 IT 探店博主 | 首发于今日头条

---

说实话，我平时刷 GitHub 的习惯就跟别人刷抖音一样，总喜欢在 trending 里瞎逛。

上周也是，没啥目的地搜了一下 `uni-app 任务管理`，然后就挖到了一个让我眼前一亮的东西——**uni-task**。

点进去一看，这不就是我一直在找的东西吗？！

---

## 先说我的背景，你们判断这东西适不适合你

我平时帮几个小团队做技术顾问，三五个人的小工作室那种，都有一个共同的痛点：

> "想用个任务管理工具，Tower 太贵，用 Excel 又太土，Notion 外网访问总抽风……"

是的，就是这么朴实的需求。不需要甘特图，不需要 OKR，就想知道**谁在做什么，做到哪了，什么时候完成**。

然后我发现了 uni-task。

---

## 第一眼：这界面……挺干净的

打开项目截图，第一感受是**干净**。没有那种把所有功能全堆在首页的感觉，就是简洁的项目列表 + 任务列表。

PC 端支持左右分栏，左边项目、右边任务，符合大家的操作习惯。移动端自适应，微信小程序和 H5 都能用。

我特意去 DCloud 插件市场（[https://ext.dcloud.net.cn/plugin?id=27219](https://ext.dcloud.net.cn/plugin?id=27219)）瞅了一眼，截图挺真实，没有那种宣传图做得老漂亮结果实际惨不忍睹的情况。

---

## 深挖功能：够用，不废话

我最怕那种任务管理工具，功能一大堆，真正用到的就那么几个，UI 还复杂得要命。uni-task 这个刚好相反，功能对着核心需求来，多余的都没有。

### 项目管理
- 创建/编辑/归档项目
- 成员管理，区分**管理员**和**普通成员**权限
- 邀请码加入——发一串码，对方扫码直接进项目组，没有繁琐注册流程

这个邀请码设计挺贴心的，小团队拉人就这么干。

### 任务管理
- 任务状态：待处理 → 进行中 → 已完成（够了）
- 优先级四档：较低 / 普通 / 较高 / 最高
- 截止日期 + 逾期提醒
- 任务分组 + **拖拽排序**（这个细节很加分）
- 子任务支持，大任务拆小任务，不怕遗漏
- 附件上传

### 团队协作
- 任务可以指派给成员
- **操作日志自动记录**——谁改了什么，改成了什么，时间线一目了然
- 项目动态实时展示
- "我的任务"个人视图，自己负责的事情不用在几十个任务里扒拉

功能说完了，大概 5 分钟就能摸透，没有学习成本。

---

## 重点来了：**它是免费的，且几乎零成本运行**

我知道有人要问了：开源 = 要自己搭服务器 = 其实并不省钱？

这里 uni-task 有个聪明的地方——它基于 **uniCloud**（DCloud 的云开发平台），后端是 Serverless 架构，不需要你买服务器、配数据库、搞运维，全部云托管。

来算一笔账（这是我自己粗算的）：

| 方案 | 10人团队，一年花多少？ |
|------|----------------------|
| Tower 专业版 | ¥39.9元/人/月 × 10人 × 12月 = **约4788元** |
| Teambition 企业版 | ¥399元/人/月起 × 10人 = **贵得离谱** |
| uni-task（uniCloud） | 小团队日常基本在免费额度内，就算超出，一年可能也就 **几十块** |

当然，你得能自己部署，或者有人帮你部署。这是有一定技术门槛的，但真的不高——官方文档说整个部署过程 **3分钟** 搞定，我实测大概 5-8 分钟（因为我网速一般，哈哈）。

---

## 部署有多简单？我帮你捋一下

1. 从 DCloud 插件市场下载或 GitHub 克隆源码
2. 用 HBuilderX 打开项目，关联一个云服务空间（注册 DCloud 账号就有免费的）
3. 一键上传云函数
4. 初始化数据库
5. 运行到浏览器/小程序/App

完了。数据就在你自己的云空间里，不在任何第三方服务商那里，数据归属完全自主。

## 技术栈快速看一眼（给开发者的）

| 类别 | 技术 |
|------|------|
| 前端框架 | uni-app (Vue 3) |
| 状态管理 | Vuex |
| 后端 | uniCloud（Serverless） |
| 用户认证 | uni-id（开箱即用） |
| 开源协议 | MIT（可商用） |

一套代码可以跑 H5、微信小程序、支付宝小程序、iOS App、Android App，有需要甚至能跑 HarmonyOS。团队成员用什么设备都无所谓。

有 Vue 基础的同学二次开发起来很顺手，主题色改两行代码就搞定，样式、组件、接口逻辑都挺规整的。

## 适合哪些人用？

老实说，它不是要跟 Tower 这种成熟 SaaS 竞争的。如果你的团队需要里程碑管理、资源负载、深度报表……那 Tower 该买还是买。

但如果你是这些情况之一：

- **初创团队**，预算有限，但需要像样的协作工具
- **小型工作室**，3-15人，只需要核心任务跟踪
- **独立开发者**，自己或小团队接单协作
- **企业内部小组**，对数据安全有要求，数据不想放在 SaaS 平台
- **uni-app 开发者**，需要一个完整的实战项目参考
- **学生团队**，做课程项目或毕业设计时的协作工具

那 uni-task 真的很值得试一试。

---

## 我觉得可以改进的地方（客观说）

探店嘛，好的说，不足的也得说：

1. **没有消息通知推送**——任务分配给你了，得自己去刷新看，不会有消息推来
2. **看板视图还没有**——习惯 Kanban 视图的朋友可能不适应（项目路线图里倒是有计划）
3. **部署需要技术基础**——对完全不懂代码的用户不友好，不过这本来就是面向开发者和技术团队的
